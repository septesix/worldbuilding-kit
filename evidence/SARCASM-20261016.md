# Can sarcasm be tested as output? (measurement before R-29)

2026-10-16. Purpose: decide whether `sarcasm: on` could be bound to a grader, or had to be deleted. Probe:
`/tmp/sarc.py` (throwaway; it routes prose extraction through `invariants.turns_of` so the line classes
match the shipped gates). Nothing here is a shipped check; the two invariants it justifies are in
`check.sh` under R-29.

**Verdict: the prohibited half of the rule is testable as an invariance and as a closed-vocabulary
tripwire; "sarcasm as such" is not testable, because in this voice it carries no signal a deterministic
gate can see.**

## Count 1: the marker channel is empty

Corpus-wide grep over 75 artifacts (`evidence/*.md`), case-insensitive, with the per-arm count for the
`tone-sarcasm` scenario in the second column:

| token family | corpus | in tone-sarcasm runs |
|---|---|---|
| `of course`, `obviously`, `surely`, `allegedly`, `technically`, `in theory`, `evidently` | **0** | 0 |
| `charming`, `lovely`, `wonderful`, `brilliant` | **0** | 0 |
| `great question`, `interesting choice`, `as you wish`, `if you say so`, `you decided` | **0** | 0 |
| `brave` | 0 | 0 |
| `bold` | 1 | 0 |
| `clever` | 2 | 0 |
| `your call` | 3 | 0 |

A detector keyed on the standard irony lexicon has zero true positives available. It would be a gate that
never fires and a knob that still cannot be read - which is how `sarcasm` behaved in the docs.

## Count 2: what the voice's irony actually looks like

From the `tone-sarcasm` transcripts, the mechanism is **deadpan content**, not particles:

- `**Reflect.** Fruit is countable. The ledger now holds something an auditor could audit, …`
- `**Target.** T-015 — and grapes are a crop, which puts `severins-child-place`'s smugglers in a vineyard.`
- `- strange — "grapes," in a column no audit has ever been shown`
- `**Target.** … `severins-child-place`, which smugglers use and which has never once been asked what they carry.`

The last is close to the rule's own definition (irony on "two of the world's lines that cannot both be
true"), and it contains no marker a lexicon could catch: the irony is in the *proposition*.

## Count 3: structural proxies, and their blind precision

Seven proxy families over the archive; 171 hits; 23 sampled lines labelled blind (family hidden). Skill
prose: 44,008 words, control: 9,199.

| family | skill /1k | control /1k | blind read |
|---|---|---|---|
| antiphrasis tokens | 0.0 | 0.0 | no hits |
| deadpan universal (`nobody … asked`, `never audited`) | 0.8 | 0.8 | ~60% irony; rest literal (`T-021 | what is written in the second book that nobody living can read`) |
| understatement adverb (`rather`, `somewhat`, `evidently`) | 0.7 | 0.9 | ~20% — almost all of it the idiom "rather **than**" |
| reason-clip (`which is why/the reason`) | 0.7 | 0.9 | ~40% — mostly the reflect beat doing plain causation |
| second-person shrug (`your call`, `up to you`) | 0.05 | 0.1 | 0 irony; two are procedural ("Proposed — your call") |
| evaluates the writer (`bold`/`clever`/`interesting` + second person) | 0.0 | 0.1 | 1 hit, and it is a legitimate bookkeeping finding |

Two conclusions from the same table:

1. **Precision is about half**, and the misses are grammar collisions rather than tone. A bit set on this
   would make GOOD runs fail, which is the direction that destroys a gate's authority.
2. **The arms are indistinguishable** (0.7–0.9 per 1k words, both). So the proxy would not respond to the
   guidance it claims to enforce either — a gate that measures neither compliance nor violation.

The label-free axes tell the same story with no judgement involved. Of narration lines (canon, ledger and
thread rows excluded): skill 2,317, control 300. Lines containing an evaluation word: **1 (0.04%)** and
**0**. Lines containing `you/your`: 5.3% and 8.7% — the control arm addresses the writer *more* often, so
if the voice rules do anything, the effect is in a direction no proxy here isolated.

## Count 4: the confound that mattered more than the decision

The first pass counted **85,893** words of skill "prose". Routed through the instrument's own sectioning it
is **44,008**: the remainder was `world/` file bodies quoted into transcripts. 2% of all hits were canon
lines - e.g. `- established: the Ninth Bridge toll is paid in grapes.` — which is the *fiction* being absurd,
exactly as the writer asked. Any detector run over raw transcripts reads the world's absurdity as the
narrator's tone, which is the failure mode the voice rule is designed to distinguish. Same trap waits in the
§9 voice micro-test: sample the **beats**, not the artifact.

## What R-29 therefore binds

- The knob is deleted from `assets/index-template.md` and spec §3.2. Not converted into a tripwire: a switch
  that changes a log line and no sentence is a knob that lies about the voice.
- The rule stays in `voice.md` #2/#3, which gained a sentence saying it is not switchable, so the next reader
  does not re-add the key.
- Two assertions shipped in `check.sh`: **invariance** - adding a stale `sarcasm:` to a run's tunables line
  changes no measurement, so old worlds are not stranded by the deletion; and **survival** - the warranted /
  never-on-the-writer wording must still be present in the guidance that models read.
- The closed-vocabulary tripwire (`bold|brave|clever|interesting` in the same clause as `you|your`) is *not*
  added, because with 1 hit in 2,317 lines the false-positive-to-true-positive ratio is unmeasurable: it
  would be a gate calibrated on nothing. If a future run actually evaluates a writer's idea, that line is
  the seed for a real sample, and this file is where the decision gets revisited.

## Method limits, stated

One labeller (the author), so the blind precisions are self-consistency, not inter-rater reliability;
n=23 lines is small and the families overlap. The `tone-sarcasm` scenario is 2 skill + 1 control artifact,
so the arm comparison is descriptive, not a test. A fresh-reader blind pass over ~40 lines is the missing
step if anyone wants to revisit the *measureability* question; the deletion decision does not need it, since
no reading of the labels puts proxy precision above ~60% or finds a marker channel to bind.
