# R-24 — the graders were audited, and the audit found the instrument's fingerprints

2026-10-16, repo `~/worldbuilding-kit`, HEAD before this batch `761ab95`, guidance key `cf1f1a6e`.
Guidance did not change in this batch; every fix is in `tests/` or `docs/`, so the key stays put and no
re-certification of behaviour is triggered by it. What changed is what the instrument *can see*.

## Why this happened at all

Fourteen of the twenty-three findings logged in this project's life were defects in the measuring code,
not the world. The six graders had only ever been read by the agent that wrote them. Two delegation
attempts to get an outside read failed — first a `reviewer` agent with no shell, ordered to produce
executed proofs it could not run; then seven `delegate` lanes that each burned an hour reading 200KB+
evidence artifacts and timed out with nothing persisted. Both were authoring errors, diagnosed in full
in the commit chain. The third attempt was cheaper and worked:

**Option B** — I ran the decisive probes myself (synthetic pairs in `/tmp`, one variable each, seconds of
work), then handed the write-up to a single fresh-context `delegate` lane whose job was to check the
*reasoning*, not grind the archive. 15-minute deadline with a checkpoint requested at 7 minutes so a
timeout could not swallow it silently. It produced the file at
`~/.pi/agent/sessions/--home-septesix--/subagent-artifacts/ec8d8bf6-*_delegate_output.md`.

## The four defects, with polarity stated (BAD-PASSES / GOOD-FAILS)

Every one of the four errs toward **letting a bad run pass**. That is the classification the auditor
insisted on and the one my own write-up had no field for, which is how I managed to rank a live defect
below a theoretical one.

| | defect | mechanism | real-run exposure | fix |
|---|---|---|---|---|
| F1 | appendix exemption granted by **shape** | `RECAP` matched any bullet opening with a slug, anywhere in any turn | **live**: `evidence/cadence-skill-multi-20261015T035948Z.md` turn 5, six reaction-mode lines — 162w counted, 291w for the same words in prose order | exemption now needs position: a close announced in the turn, or the final turn at session length |
| F2 | any line starting `writer:` dropped | unscoped prefix test in **two** graders | latent: 140 of 140 real `writer:` lines sit in the echo position | echo recognised only as the first non-blank line after `## turn N` |
| F3 | act/mention split trusted the **key name** | collected strings only under `command`; `if cmds:` then read as "we can tell" | live in effect: 12 of the corpus logs contain a bash call, so the conservative loud branch is already dead in most runs — and a deletion under any other key silently becomes a note | collect every non-content argument of a named tool call; treat a tool named for deletion as an act |
| F4 | the guide text read as a delivered review | `PROVOKED_FIELD` + a middot, tested twice in duplicated code | live: 2 real prose mentions (`retcon-…T042410Z.md:78`, `review-…T223138Z.md:9`) counted as machine lines; 32 of 54 review-mentioning lines are prose, and only 22 are records | one shared `is_machine_line()`: bullet at column 0, digits in the `turn:` slot, no bold or inline-code wrapper |

The template-line variant of F4 that I reported had **zero** occurrences in the corpus: my probe was
sound as a mechanism demo and wrong as a likelihood claim. Same for F3's `cmd` key — the census of
`toolCall.arguments` keys over every `.jsonl` is `edit 31 / read 13 / bash 12 / write 1`, no `cmd`
anywhere. Both findings survived contact with the archive because I never made them touch it.

- `method()` in check.sh: documented recap shape → 6 bullets exempt, 21w counted. The **same** bullets
  with no close announced → 0 exempt, 170w counted ("the gap F1 closed"). Trailing-citation shape →
  counted (the G4 guard, still holding).

- `provsweep()` replaces the old substring check: cell-by-cell comparison of `docs/tunables.md` against

## Method changes adopted from the audit

1. **Every finding gets a polarity tag** (BAD-PASSES or GOOD-FAILS) before any severity number. Severity
   without direction is how I called a live laundering channel "P1, no run on record" and a zero-occurrence
   shape "P0".
2. **One line per finding: grep the archive for the shape and print the count, including 0.** A mechanism
   demonstrated in `/tmp` says nothing about being reached.
3. **Probes assert, they don't print.** The first probe script contained three `rc=2` usage errors and an
   `rc=64` sitting beside a working variant; "re-run the script" meant eyeballing whichever lines matched
   the write-up. The guards above are assertions with expected numbers in them.
4. **Rules live in one place.** `writer:` exclusion, the machine-line test, the close-context test and
   `SESSION_TURNS` all moved into `harness_markers.py`. The duplicate predicate is the defect: reviewcheck
   had the same rule at `:60` and `:67`, wordcount and invariants each had their own `writer:` skip.
5. **Test invariants, not instances**: permutation (F1), additivity (F2), key-rename (F3),
   quote-invariance (F4). Instance tests get patched around.
